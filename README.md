# openEuler Linux Labs

Hands-on, reproducible Linux labs for **openEuler**, designed to help learners
build real system administration skills through practice, not memorization.

This repository is organized by **chapters**, with each chapter containing
multiple labs that simulate real-world Linux scenarios.

---

## Who This Is For

- Students learning Linux using openEuler
- openEuler certification candidates
- Anyone who wants practical Linux administration experience
- Self-learners who prefer hands-on labs over tutorials

---

## Lab Structure

Each lab is self-contained and includes:

- `README.md` – lab overview and objectives
- `setup.sh` – prepares the lab environment
- `tasks.md` – problems to solve
- `check.sh` – verifies whether the lab was completed correctly
- `solution.md` – explanation and reasoning

Not all labs will include all files, but the goal is **reproducibility**.
